Baybo Agent Support

Help and troubleshooting for the Baybo Agent iOS app and its connection to your self-hosted Baybo gateway.

Contact support

If you have a question, found a bug, or need help connecting the app, submit a support request. Describe what you expected, what happened, your iOS/iPadOS version, and the Baybo version you are using. Please remove tokens, API keys, private messages, and other sensitive data before posting.

Quick help

The app cannot connect to my gateway
  1. Confirm the Baybo gateway is running with baybo status --live.
  2. Make sure the phone and gateway can reach the internet, or are on the same reachable local network.
  3. If pairing expired or was revoked, create a new pairing code and scan it again.
  4. If the problem continues, include relevant gateway logs in your support request after removing secrets and personal data.
Pairing or QR-code setup fails

Generate a fresh code with baybo device pair, keep the terminal open, and scan the new code in the app. Confirm the displayed verification code on both devices before approving.

Messages are delayed or notifications are missing

Check that notifications are enabled for Baybo Agent in iOS Settings and that the gateway is online. Network changes, Low Power Mode, relay availability, and notification settings can affect delivery.

Where is my data stored?

Baybo is self-hosted. Session data is stored by the Baybo gateway you connect to. The iOS app is a companion client; review and manage the gateway you paired with before sharing sensitive information.

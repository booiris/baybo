Troubleshooting

More detail before you contact support.

The app cannot connect to my gateway
  1. Confirm the gateway is running with baybo status --live.
  2. Make sure the phone and gateway have network access or share a reachable local network.
  3. If pairing expired or was revoked, generate and scan a new pairing code.
  4. If it still fails, email support with sanitized gateway logs.
Pairing or QR-code setup fails

Generate a fresh code with baybo device pair, keep the terminal open, and scan the new code. Confirm the same verification code on both devices before approving.

Messages or notifications are delayed

Confirm the gateway is online and notifications are enabled for Baybo Agent. Network changes, Low Power Mode, relay availability, and notification settings can affect delivery.

Where is my data stored?

Baybo is self-hosted. Session data is stored by the Baybo gateway you connect to. Review and manage the gateway you pair with before sharing sensitive information.
